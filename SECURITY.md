## Supported versions

Only the latest release on the Releases page receives fixes.

## Reporting a vulnerability

Do not report security problems in public issues.

Use Report a vulnerability on GitHub to send a private report. Please include:

- what an attacker can do
- steps to reproduce
- your Paper and HitHealth versions

You will get a reply within 7 days. Once a fix is released, the report may be published as a security advisory.
